:::note[Where the example stands]
Booted with `just example up`. `just example reset` gets you back to that from any step.
:::

```bash
just example down
```

In your own repository, most of what you did here needs no config at all. Start with a dry run:

```bash
terragucci reconcile --config terragucci.yml
```

[Your config file](/terragucci/getting-started/config/) covers the rest, and [For agents](/terragucci/getting-started/agents/) has a prompt that lets a coding agent do it for you.
