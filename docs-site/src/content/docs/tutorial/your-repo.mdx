:::note[Where the example stands]
Booted with `just example up`. `just example reset` gets you back to that from any step.
:::

```bash
just example down
```

That removes the whole local stack, the Terragrunt shop included.

In your own repository `terragucci init` finds the roots and the binary and the forge itself. Most repos need no config.

[Get your first plan note](/terragucci/getting-started/) takes you from `npm i -D @intentius/terragucci` to a plan note on a pull request. Before the first merge, [set up the signers file](/terragucci/guides/approve-a-wave/#set-up-the-signers-file) so a person can approve the waves that wait.

[terragucci.yml keys](/terragucci/reference/config/) covers the config, and [Set up with a coding agent](/terragucci/getting-started/agents/) has a prompt that lets an agent do it for you.
