:::

```bash
just example down
```

In your own repository, most of what you did here needs no config at all. [Get your first plan note](/terragucci/getting-started/) takes you from `npm i -D @intentius/terragucci` to a plan note on a pull request.

[terragucci.yml keys](/terragucci/reference/config/) covers the config, and [Set up with a coding agent](/terragucci/getting-started/agents/) has a prompt that lets an agent do it for you.
