:::note[Where the example stands]
Booted with `just example up`. `just example reset` gets you back to that from any step.
:::

An approval covers the plans you read and no others. Merge `just example change destroy` so wave 4 waits, then approve it with `just example approve` as on the previous page. Before you run the wave's job again, run `just example change module-bump` and `just example merge module-bump`, which changes the shared module so every root in wave 4 plans again.

<Captured step="wave-refused" optional />

The wave's plans now differ from the approved ones. It applies nothing and the job fails with exit code 4. The log names each root whose plan moved. It prints the approved digest beside the new one.

<Shot step="wave-refused" view="log" alt="Wave 4's apply job in Forgejo, refusing: the approved digest beside the planned one, and the eight roots that planned differently" optional />

`npx terragucci respond wave-refused --approved <approved report> --current <current report> --wave 4` prints what changed; [Fix a refused wave](/terragucci/guides/fix-a-refused-wave/) describes the reports.

If the new plan is what you meant, approve the new digest and run the job again. Otherwise revert the change.
