Every queue in every service should wait 60 seconds before retrying a job. That is one line in `modules/service`, and twelve roots call the module.

<Captured step="one-note" optional />

Open the pull request link it printed, on Forgejo at `localhost:3300`; the plan note is the comment in the conversation.

terragucci plans only the twelve service roots the change reaches and posts one note. Eleven roots take the identical change and appear as one group. Prod payments sits apart, because its dead-letter queue changes too.

The note links to the full report. Its links start with `http://forgejo:3000`, which your browser cannot reach; open them at `http://localhost:3300` instead. The report opens on what differs and folds the eleven identical plans into one.

Next, try `just example change replace` and `just example change destroy`. Each is named on its own, never folded into a group.
