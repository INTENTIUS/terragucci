## Change one root

Orders in dev should keep unpicked jobs for seven days instead of four: one line in `envs/dev/orders/main.tf`.

<Steps>

1. Make the branch and open the pull request with one command. The push and the pull request each start a run: the pull request's run posts the plan note and the push's run is the check. Take the run numbers from the output.

   <Captured step="first-pr" />

2. Open the pull request link in Forgejo:

   <Shot step="first-pr" view="files" alt="The pull request's files tab, adding job_retention_seconds = 604800 to dev orders" />

3. Look at the push's run, the second link printed. `tf-check` runs on the branch push, and on a pull request only from a fork: a format check, then `validate` for every root. Both steps pass. The plan note is a comment in the conversation:

   <Shot step="first-pr" view="pull" alt="The pull request in Forgejo with its check passing and its plan note for the one root" />

</Steps>

## Break the formatting

<Steps>

1. Add a badly formatted file:

   ```hcl
   locals {
       team   = "orders"
     owner = "shop"
   }
   ```

2. The scenario opens it as a second pull request. The check fails, and `just example logs` prints the file and the change `tofu fmt` would make.

   <Captured step="check" />

3. In Forgejo the failed step is "Format check and validate, every root":

   <Shot step="check" view="log" alt="The failed check job in Forgejo, its format step open on the diff tofu fmt -check printed for envs/dev/orders/locals.tf" />

4. Run `tofu fmt -recursive` in your own repo and the check goes green again.

</Steps>

## What you saw

Every push runs the check stage on every root. It needs no cloud credentials, because it never plans.
