A pipeline that only parses has not been tested. Before a release, every pipeline terragucci generates runs on a real forge, with a real runner, against an AWS emulator. Each feature has a check that must pass, and each check is also broken on purpose to show it fails when it should.

| Forge | What runs |
|---|---|
| Forgejo | a Forgejo server and its runner |
| GitHub | the generated workflow, run by `act` against a mock GitHub API |
| GitLab | GitLab CE and its runner |

Forgejo, GitHub and the AWS emulator are checked on every pull request to terragucci. GitLab is checked every night, because its server is heavy.

## The claims

Each claim runs once as it should, and once with the property it checks broken on purpose; the claim must then fail. `reconcile` runs `terragucci reconcile` from a control repo and follows the pull or merge request it opens through its check, its merge and the apply that follows. The `tg-` claims run the generated pipeline for a Terragrunt repo of two units, and the `cdf-` claims run it for a [choudoufu](/terragucci/concepts/glossary/#choudoufu) estate, each in the CI image that pipeline pins: `cdf-check` fails a resource that `choudoufu live-check` refuses, and `cdf-apply` finds the estate marker on the bucket it created.

## The example's checks

Each feature has one check, run against the [tutorial's example](/terragucci/tutorial/) on a local Forgejo. A check that passes has also been broken on purpose, and it failed then.

The same setup runs on your laptop. [The tutorial](/terragucci/tutorial/) boots it with one command and walks through each feature.

## Running it yourself

```bash
just stack-up forgejo
just smoke
just stack-down
```

To run a single claim on a forge, use `just validate <forge> <claim>`. To run all of a forge's claims, plain and broken, use `just validate-forge <forge>`. After a full run, `just validation-record` rewrites the table above.

`just smoke` prints one line per check. `BREAK=1 just smoke <check>` breaks the property on purpose, and the line must then say `caught`.
