Release `0.4.7` is on npm as `@intentius/terragucci@0.4.7`, and its [GitHub release](https://github.com/INTENTIUS/terragucci/releases/tag/v0.4.7) lists every change.

| To upgrade | Run |
|---|---|
| Each repo | `npx @intentius/terragucci@0.4.7 init`, then merge the pipeline it writes |
| Each approver | `terragucci approve` where you ran [`chant approve`](/terragucci/concepts/glossary/#chant); installing terragucci is enough ([approve](/terragucci/reference/cli/#approve)) |

## From 0.4.5

0.4.6 carries every change of 0.4.5, listed by area below. Upgrading from 0.4.4 or earlier, also note:

| From 0.4.4 | Run |
|---|---|
| A Terragrunt repo that uses `generate` | `terragucci generate` again, so each unit's state key reads the ephemeral suffix ([In a Terragrunt repo](/terragucci/guides/generate-root-files/#in-a-terragrunt-repo)) |

- Changed default: a pull request that changes a Terragrunt unit also previews the units that depend on it, provisional and outside every digest. Set `terragrunt.dependents: follow` to keep the old behavior ([The terragrunt block](/terragucci/reference/config/#the-terragrunt-block)).
- Applies now run per root. With stock binaries, two overlapping pushes to one root can fail the newer apply with "Saved plan is stale"; run it again and it plans again ([Two applies of one estate](/terragucci/concepts/locking-and-staleness/#two-applies-of-one-estate)).
