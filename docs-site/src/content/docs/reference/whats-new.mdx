terragucci 0.4.4 is on npm as `@intentius/terragucci@0.4.4`, and its [GitHub release](https://github.com/INTENTIUS/terragucci/releases/tag/v0.4.4) lists every change.

| To upgrade | Run |
|---|---|
| Each repo | `npx @intentius/terragucci@0.4.4 init`, then merge the pipeline it writes |

## Since 0.4.4

| What | Where |
|---|---|
| Changed default: a pull request that changes a Terragrunt unit also previews the units that depend on it, provisional and outside every digest. Set `terragrunt.dependents: follow` to keep the old behaviour | [terragucci.yml keys](/terragucci/reference/config/#the-terragrunt-block) |
| `generate.disable_init: false` writes `disable_init = false` in `terragucci.hcl`, and the apply job has Terragrunt create the state bucket | [Generate backend and provider files](/terragucci/guides/generate-root-files/#bucket-bootstrap) |

## Security

| What | Where |
|---|---|
| A sensitive value's old value no longer reaches plan.json, the report or the bucket: OpenTofu repeats some sensitive inputs unmarked, and terragucci now redacts those copies too | [Report](/terragucci/reference/report/) |
| The policy reads an AI review's verdict from the review job's own artifact for that head, never from a comment | [Review a pull request with an agent](/terragucci/guides/agent-review-a-pull-request/) |

## Plans across roots

| What | Where |
|---|---|
| A root that reads another's state plans on that root's planned outputs, with unknown values named, and its wave plans again once the upstream applies | [Waves and approvals](/terragucci/concepts/waves-and-approvals/) |
| Each apply writes a run page to your bucket: the waves, what each reads, and where each stands | [Reports bucket](/terragucci/reference/reports-bucket/) |
| The estate page draws each project's dependency graph, and the plan note and run page show a change's blast radius and a timeline of each wave | [See every project](/terragucci/guides/see-every-project/) |
| `waves.jobs` spreads a wide wave's roots across jobs under one gate | [Waves and approvals](/terragucci/concepts/waves-and-approvals/#a-wide-wave-across-jobs) |

## State

| What | Where |
|---|---|
| Each apply records its state version, listed on the estate page | [See every project](/terragucci/guides/see-every-project/) |
| `terragucci unlock-state` releases a lock a killed job left, only after an approval and with a record of who did it | [Release a state lock](/terragucci/guides/release-a-state-lock/) |
| Migration files move resources between roots or to a new backend, planned with zero changes, approved by digest, with a gated revert | [Move resources between roots](/terragucci/guides/move-resources-between-roots/) |

## Approvals and review

| What | Where |
|---|---|
| Approve and Decline buttons in Slack, and an approving reply in Teams, through `terragucci relay`, which you run | [Approve from Slack and Teams](/terragucci/guides/approve-from-chat/) |
| An AI review of a pull request's description against its plan, on your own model, from instructions on the default branch; it never approves | [Review a pull request with an agent](/terragucci/guides/agent-review-a-pull-request/) |
| `cost.approve_above` holds a wave whose monthly cost change is over the amount, and cost is in the policy input | [Estimate the cost of a change](/terragucci/guides/estimate-cost/) |

## Your setup

| What | Where |
|---|---|
| `steps` run your commands before and after each stage; a failed `approve` step holds the wave | [Run your own steps](/terragucci/guides/run-steps/) |
| Each root pins its own OpenTofu or Terraform version | [Choose your binary](/terragucci/guides/use-a-binary/) |
| `terragucci generate` writes each root's backend, provider and version files from `terragucci.yml` | [Generate backend and provider files](/terragucci/guides/generate-root-files/) |
| `terragucci import atlantis` and `import digger` write `terragucci.yml` from your existing config | [Coming from Atlantis or OpenTaco](/terragucci/guides/coming-from-atlantis-or-opentaco/) |
| A tip opens a pull request that writes the `moved` block for a rename, so it plans as a move | [Tips](/terragucci/reference/tips/) |
| DORA metrics on the estate page and as OTLP gauges | [Delivery metrics](/terragucci/reference/delivery-metrics/) |

## Terragrunt and CDK Terrain

| What | Where |
|---|---|
| `modules.require: attested` is enforced for each Terragrunt unit | [Publish modules](/terragucci/guides/publish-modules/) |
| CDK Terrain stacks apply through gated waves, and the tips job synthesizes first | [Plan CDK Terrain stacks](/terragucci/guides/plan-cdk-terrain-stacks/) |
