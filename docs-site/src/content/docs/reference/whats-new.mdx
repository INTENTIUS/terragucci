terragucci 0.4.2 is on npm as `@intentius/terragucci@0.4.2`, and its [GitHub release](https://github.com/INTENTIUS/terragucci/releases/tag/v0.4.2) lists every change.

| To upgrade | Run |
|---|---|
| Each repo | `npx @intentius/terragucci@0.4.2 init`, then merge the pipeline it writes |

## One audit trail

| What | Where |
|---|---|
| `terragucci audit` writes every approval, apply, policy override and refused wave across your projects to one record in your bucket, as JSON lines, with a page linked from the estate page | [Audit trail](/terragucci/reference/audit-trail/) |

## New settings

| What | Where |
|---|---|
| `synth`: run `cdktn synth` (or any command that writes the roots) before the jobs read them | [Plan CDK Terrain stacks](/terragucci/guides/plan-cdk-terrain-stacks/) |
| CDK Terrain on cdktn 0.24.0, and a pull request plans only the stacks whose synthesized output changed | [Plan CDK Terrain stacks](/terragucci/guides/plan-cdk-terrain-stacks/) |
| `notify`: a waiting, refused or failed wave posts to Slack or Teams | [Tell a chat channel when a wave stops](/terragucci/guides/notify-a-chat-channel/) |
| `cost`: a monthly cost estimate per root in the plan note, from Infracost on your key | [Estimate the cost of a change](/terragucci/guides/estimate-cost/) |

## Large estates

| What | Where |
|---|---|
| A wave applies at most `parallelism` roots at once; before, it applied every root of the wave together | [Config](/terragucci/reference/config/) |
| `parallelism` defaults to 4 instead of 16, so a wave of AWS roots fits a 7 GB runner | [terragucci.yml keys](/terragucci/reference/config/#keys) |
| A wave's roots share one provider cache, and plan and drift stages download each provider once instead of once per root | [Pipeline](/terragucci/reference/pipeline/) |

## Fixes

| What | Where |
|---|---|
| An approval that already applied no longer refuses the next wave; under `approval: pr-review` every merge after a review-approved apply was refused before | [Approve a wave](/terragucci/guides/approve-a-wave/) |
| A policy override that already applied no longer refuses the root's next plan: the new denial is recorded and waits for its own override | [Overriding a denial](/terragucci/reference/policy/#overriding-a-denial) |
| `reconcile` writes the control repo's `reports` into each project's `terragucci.yml`, so apply waves copy their reports to the bucket | [Govern many repos](/terragucci/guides/govern-many-repos/) |
| The Terraform image is 1.14.9, so `terraform query` imports generate config | [Choose your binary](/terragucci/guides/use-a-binary/) |
| Rollouts read an empty Forgejo repo as having no pull requests | [Roll out a new module version](/terragucci/guides/roll-out-a-module-version/) |
| An import that also updates a resource is named in the report | [Report](/terragucci/reference/report/) |
| `trust.json` is read the way [chant](/terragucci/concepts/glossary/#chant) reads it, and fails closed without `"schema": 1` | [Approve a wave](/terragucci/guides/approve-a-wave/) |
