terragucci 0.4.0 is on npm as `@intentius/terragucci@0.4.0`, and its [GitHub release](https://github.com/INTENTIUS/terragucci/releases/tag/v0.4.0) lists every change.

| To upgrade | Run |
|---|---|
| Each repo | `npx @intentius/terragucci@0.4.0 init`, then merge the pipeline it writes |

## Approvals

| What | Where |
|---|---|
| One `approval:` key: `ledger` (the default, no signing), `pr-review` or `sealed` | [Approve a wave](/terragucci/guides/approve-a-wave/) |
| `terragucci approve` finds the waiting wave and its digest | [Approve a wave](/terragucci/guides/approve-a-wave/) |
| The project token's own approval never counts | [Threat model](/terragucci/reference/threat-model/) |

## Pull requests

| What | Where |
|---|---|
| Apply before merge on GitHub, GitLab and Forgejo, Terragrunt repos included | [Apply before merge](/terragucci/guides/apply-before-merge/) |
| `apply.requires`, `/terragucci lock` and `/terragucci unlock` | [Apply before merge](/terragucci/guides/apply-before-merge/) |
| `locks: plan` on GitHub and Forgejo | [Config](/terragucci/reference/config/) |
| Comment commands on GitLab, with no server | [Re-plan from a comment](/terragucci/guides/re-plan-from-a-comment/) |
| The plan note shows each change's diff and links the report in your bucket | [Report](/terragucci/reference/report/) |

## Waves, policy and reports

| What | Where |
|---|---|
| Terragrunt waves follow the dependency layers | [Use Terragrunt](/terragucci/guides/use-terragrunt/) |
| `policy.source` shares one policy across repos | [Policy](/terragucci/reference/policy/) |
| A recorded policy override | [Policy](/terragucci/reference/policy/) |
| One page for every project, in your bucket | [See every project](/terragucci/guides/see-every-project/) |
| Reports in S3, GCS or Azure Blob | [Keep reports in a bucket](/terragucci/guides/keep-reports-in-a-bucket/) |
| The plan says when drift checks are overdue | [Turn on drift checks](/terragucci/guides/turn-on-drift-checks/) |
