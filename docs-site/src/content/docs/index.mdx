## The lifecycle around your roots

terragucci carries a root through review, rollout and the watch that follows, and you write none of the pipeline. The stages are built on [chant](https://intentius.io/chant/), which renders each one into a workflow for your forge. Your Terraform code and its state stay yours.

<Lifecycle />

## One note for two hundred plans

A change to a shared module can touch hundreds of roots. Your reviewer gets one note on the pull request that groups the roots taking the same change. Every destroy and every replacement is still named.

<PlanNote />

The note links to the full report. It opens on the destroys and the outliers with the identical groups folded away, and every root in it links to its full plan. Scripts read the same data as JSON. [The plan report](/terragucci/reference/report/) shows both.

## Rollouts in waves

The change goes out a few roots at a time. Each wave waits for its own approval, and that approval covers exactly the plans it was given.

<Waves />

Each wave's state and set digest are in the report, linked to the approval record that let it go out. A pinned module rolls out the same way, one pull request per wave, across as many repos as use it.

## Three ways in

| You want to | Start here |
|---|---|
| see it work first | [The tutorial](/terragucci/tutorial/) runs a 15-root example on your laptop, with a local forge and an AWS stand-in |
| use it on your own repo | [Get your first plan note](/terragucci/getting-started/) takes `npm i -D @intentius/terragucci` and `npx terragucci init` to a plan note on a pull request |
| hand the setup to your agent | paste the prompt at the top of this page into Claude Code, Codex or Cursor; [the agent page](/terragucci/getting-started/agents/) says what it does. It never applies and never approves |

Once it runs, the [how-to guides](/terragucci/guides/add-to-github/) cover the tasks, the [reference](/terragucci/reference/config/) the details, and the [concepts](/terragucci/concepts/waves-and-approvals/) the reasons behind them.

[How terragucci compares](/terragucci/compare/) sets it beside Atlantis, HCP Terraform, Spacelift and Digger.
