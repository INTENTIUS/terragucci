## Reading the grid

Atlantis is a server you host that applies before merge. OpenTaco (formerly Digger) runs in your CI with an orchestrator, and holds state only if you choose its state service. HCP Terraform and Spacelift are services; both put drift checks and git-kept policy on paid tiers.

terragucci adds no server; its strongest rows are the grouped note and digest-bound wave approvals. Partial rows say what it does instead.
